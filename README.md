# DGIFOZ — Sistema Web de Gerenciamento e Acompanhamento de Pedidos

Protótipo funcional de front-end criado para o Projeto de Extensão IV.

## Como executar
1. Extraia esta pasta.
2. Abra `index.html` em um navegador moderno.
3. Não é necessário instalar Node, npm ou banco de dados.

## Funcionalidades
- Dashboard com indicadores e próximos prazos.
- Cadastro de pedidos.
- Alteração de status pelo fluxo:
  NOVO PEDIDO → ORÇAMENTO → AGUARDANDO APROVAÇÃO → APROVADO → EM PRODUÇÃO → FINALIZADO → ENTREGUE.
- Histórico do pedido.
- Pesquisa e filtro por status.
- Cadastro de clientes.
- Página institucional/operacional da empresa.
- Uso das fotos fornecidas para o projeto.
- Persistência local dos dados via `localStorage`.

## Observação acadêmica
Os cinco pedidos exibidos inicialmente são **dados demonstrativos/fictícios**, usados somente para apresentar o funcionamento da interface. Eles não devem ser apresentados como clientes reais da empresa.

O sistema é um protótipo front-end. Para uso comercial real, a próxima etapa seria implementar autenticação, banco de dados no servidor, controle de permissões, armazenamento seguro de arquivos, backups e políticas de privacidade.

## Referência visual
A interface segue os princípios solicitados de hierarquia visual, organização por cards, tipografia moderna, espaçamento, bordas arredondadas, sombras suaves, CTAs destacados, responsividade e acabamento de produto comercial. A referência da UniAmérica é utilizada somente como inspiração de design/experiência, sem copiar identidade visual.
